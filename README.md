# Phantombass Labor

Hörtest für virtuellen Bass im Browser: https://julianschneider3618-beep.github.io/Musik-open/

Tiefe Töne, die ein kleiner Lautsprecher nicht abspielen kann, werden in Obertöne
umgewandelt, aus denen das Ohr den fehlenden Grundton ergänzt. Mit Tonhöhenerkennung,
automatischer Lautstärke und Lautsprecher-Messung über das Mikrofon.
